# Local GPU stack: AMD Radeon RX 7900 XT (gfx1100) on Windows 11.
#
# PREREQUISITES -- verify both before installing:
#   1. AMD graphics driver >= 26.2.2  (Adrenalin -> Settings -> System -> Software)
#   2. Python 3.12 exactly. These wheels are cp312-only; 3.11 or 3.13 will not resolve.
#
# Install order matters -- the ROCm SDK must land before torch.
#
#   python -m pip install -r requirements-rocm.txt
#   rocm-sdk init
#   python -m pip install -e ".[dev]"
#
# REQUIRED: `rocm-sdk init` (between the two pip installs above) unpacks the
# ROCm runtime libraries that the torch wheels link against. It is NOT run
# automatically by pip; skipping it makes `import torch` fail with a cryptic
# DLL-load error ("shm.dll not found" or similar) rather than anything that
# mentions ROCm. If torch import fails after a fresh install, run it and retry.
#
# Then gate on: python scripts/verify_env.py
