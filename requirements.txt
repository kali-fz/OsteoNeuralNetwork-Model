# Root requirements — used by Streamlit Community Cloud, which installs from
# `requirements.txt` at the repository root and nowhere else.
#
# CPU torch on purpose. Community Cloud has no GPU, and the CUDA wheels are
# ~2.5 GB, which would blow the build long before it ran. Inference on CPU at
# 256px is a second or two per image, which is fine for a demo.
#
# For LOCAL development do NOT install this file:
#   AMD/ROCm  -> requirements-rocm.txt   (the 7900 XT stack)
#   NVIDIA    -> requirements-cuda.txt   (or let Colab/Kaggle supply torch)
# Installing this one over a ROCm environment would replace the ROCm build with
# a CPU one and silently disable the GPU.
